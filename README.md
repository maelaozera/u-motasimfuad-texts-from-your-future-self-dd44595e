One funny text message, under 200 characters, sent by your future self back to your present self. No setup, no context — just the message as it would arrive. A house judge compares entries pairwise on whether the joke lands, whether the voice feels like a real future self, how well every character is used, and how fresh the angle is.

Entry: It's 2036. You finally finish the side project. It makes $4. Nobody cares. You care. Keep going, you stubborn idiot.

Run with `node main.ts`; it writes the text to `/output/entry.txt`.
